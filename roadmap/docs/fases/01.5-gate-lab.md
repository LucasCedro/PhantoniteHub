# Gate lab — checklist (Fase 1.5)

Não é feature de código. É **uma sessão real** com o HUB aberto.

## Setup (5 min)

- [ ] Lab autorizido escolhido (THM / PortSwigger / box local — o que for)
- [ ] `guide.html` no browser + Kali/terminal ao lado
- [ ] Params: IP / TARGET / LHOST preenchidos
- [ ] RoE do HUB faz sentido pra esse lab

## Fluxo (mínimo)

- [ ] RoE → session → chega em ramo **web**
- [ ] Abre `web-ssrf` **ou** `web-jwt` **ou** `web-sqli` (o que o lab pedir)
- [ ] Testa **Field** (observe / hipóteses / testes) enquanto ataca
- [ ] Alterna **Study** (`K` ou botão) — teoria ajuda ou atrapalha?
- [ ] Copia ≥1 cmd do nó — hydrate OK?
